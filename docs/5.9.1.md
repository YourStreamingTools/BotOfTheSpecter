# Changelog - Version 5.9.1

## Version Information

* Updated version from 5.9 to 5.9.1

## Bug Fixes

* **Known bots and excluded users no longer earn points from events**
  * Raids, cheers, subscriptions, resubscription messages and follows now skip points for accounts on the global known bots list and for the channel's Excluded Users, the same as chat points already did.
  * Matching is case-insensitive, and no points entry is created for a skipped account. Alerts, stream credits and subathon time are unchanged.
