# Changelog - Version 5.9.2

## Version Information

* Updated version from 5.9.1 to 5.9.2

## Bug Fixes

* **Spotify song requests no longer follow the media player request toggle**
  * When Spotify is connected, `!songrequest` now works even if requests are turned off on the Media Player page. That toggle only controls requests played through the local media player and overlay.
  * If Spotify is not connected, requests fall back to the local media player, which still follows the toggle. Per-viewer limits are unchanged.
