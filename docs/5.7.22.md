# Changelog - Version 5.7.22 (2026-09-19)

## Version Information

* Updated version from 5.7.21 to 5.7.22
* Fix: `!setgame` no longer reports failure after Twitch has already updated the category

## Bug Fixes

* **`!setgame` said the update failed even when the category changed**
  * Helix `PATCH /helix/channels` returns **204 No Content** on success. Stable only treated HTTP 200 as success, so chat posted `Failed to update game` with an empty error body after a successful change.
  * **Fix:** Treat 200 and 204 as success for category and title updates. Real failures now include the HTTP status in the error text.

## Technical Details

* `update_twitch_game` and `trigger_twitch_title_update` accept HTTP 204 as success.
