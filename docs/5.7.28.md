# Changelog - Version 5.7.28 (2026-10-13)

## Version Information

* Updated version from 5.7.27 to 5.7.28
* Fix: the bot sends its API key in a request header instead of the web address when it notifies overlays

## Bug Fixes

* **The channel's API key was in the web address of every overlay notice**
  * Each time the bot told overlays about an event (follows, cheers, raids, sound alerts and more), it put the channel's API key in the request's web address. Web addresses are saved in server access logs.
  * The bot's websocket log also wrote the key out in full for every notice that was sent.
  * **Fix:** The key is sent in the `X-API-KEY` header and is no longer part of the logged details.

## Technical Details

* `websocket_notice` calls `https://websocket.botofthespecter.com/notify` with an `X-API-KEY` header, the V2 way of passing the key. The websocket server reads the header first and still accepts `?code=` from older bots.
