# Changelog - Version 5.9.3

## Version Information

* Updated version from 5.9.2 to 5.9.3

## New Features

* **Set a permission when adding a command from chat**
  * `!addcommand` now accepts a quoted permission straight after the command name, for example `!addcommand stabcount "mod" Bandit has stabbed themself (count.stabs) times today.`
  * Accepted permissions: `everyone`, `mod` (or `mods`), `vip` (or `vips`), `sub` (or `subs`, `subscribers`) and `broadcaster`. Sub permissions allow all subscriber tiers.
  * Commands added without a permission still default to everyone, and the existing `!addcommand [command] "[response]" [permission]` format still works.
