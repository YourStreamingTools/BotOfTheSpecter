# Changelog - Version 5.9.6

## Version Information

* Updated version from 5.9.5 to 5.9.6

## Bug Fixes

* **`!stoptimer` works again for personal timers**
  * `!stoptimer` was removed when `!timer stop` became the way to cancel a personal timer, but viewers still use it and it is still noted in the docs.
  * The command is back on the stable and beta bots. It cancels your personal timer the same way as `!timer stop`, with the same replies: "your timer has been cancelled" or "you have no active timer to cancel".
  * It has its own builtin command row, a per-user cooldown, and zero cooldown with the other task commands. The row is created the next time the bot starts.
