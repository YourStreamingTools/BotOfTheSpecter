# Changelog - Version 5.9 (UPCOMING UPDATE)

## Version Information

* Updated version from 5.8 to 5.9

## Improvements

* **Timed messages pause during a rerun**
  * While a scheduled VOD rerun is playing, timer, chat-line, and clock-time timed messages stay off so they do not flood chat.
  * They start again when that rerun finishes and the stream is still online. A bot restart during the rerun leaves them paused. Going offline still clears them as before.
  * V6 pauses its timer and chat-line timed messages the same way. V6 has no clock-time timed messages.
