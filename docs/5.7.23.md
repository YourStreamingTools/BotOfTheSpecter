# Changelog - Version 5.7.23 (2026-10-01)

## Version Information

* Updated version from 5.7.22 to 5.7.23
* Fix: weather temperatures in chat now show as whole degrees

## Bug Fixes

* **Weather chat showed long decimals**
  * A forecast such as 12.87°C (55.17°F) was posted with the raw decimals from the weather service.
  * **Fix:** Celsius and Fahrenheit in the weather chat message round to the nearest whole degree. Halves round away from zero, so 12.5°C becomes 13°C.

## Technical Details

* `process_weather_websocket` rounds both temperature values before sending the chat message.
