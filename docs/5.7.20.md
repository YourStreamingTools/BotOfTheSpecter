# Changelog - Version 5.7.20 (2026-08-21)

## Version Information

* Updated version from 5.7.19 to 5.7.20
* Fix: offline chat is not recorded in `seen_today` until the stream is live

## Bug Fixes

* **Welcome messages skipped after offline chat**
  * If a viewer spoke in chat while the stream was offline, they were written to `seen_today` immediately.
  * When the stream went live, they were already marked as seen for the session, so the welcome never fired.
  * **Fix:** `seen_today` and the welcome only run while the stream is online. `seen_users` is unchanged (known-user registry still updates offline).

## Technical Details

* `message_counting_and_welcome_messages` requires `stream_online` before inserting `seen_today` or sending a welcome.
