# Changelog - Version 5.7.26 (2026-10-08)

## Version Information

* Updated version from 5.7.25 to 5.7.26
* Fix: the gift sub chat message no longer says "You have gifted a total of 0" (or "None")

## Bug Fixes

* **Gift sub message showed a total of 0 or None**
  * When a gifter's total isn't shared, the gift sub thank-you message said "You have gifted a total of 0 to the community!" (or "None" for anonymous gifts), even for viewers who have gifted many subs.
  * **Fix:** When Twitch doesn't share the gifter's total, the sentence about the total is left out. When Twitch does share it, it still shows as before.

## Technical Details

* Twitch sends `cumulative_total` as `null` for anonymous gifts and as `0` when the gifter's total isn't shared. A real total always includes the current gift, so a value below the number of subs gifted is treated as not shared, and the sentence containing `(total-gifted)` is removed from the message.
