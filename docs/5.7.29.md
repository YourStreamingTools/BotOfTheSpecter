# Changelog - Version 5.7.29 (2026-10-13)

## Version Information

* Updated version from 5.7.28 to 5.7.29
* Fix: each log file covers one day, and only the last seven days are kept

## Bug Fixes

* **Log files had no daily limit**
  * A log file stayed open until it reached 10 MB. A quiet day left weeks of lines in one file. A busy day dropped older lines after a few hours.
  * **Fix:** At midnight in the channel's timezone, today's log is closed and kept as the previous day. Six earlier days are kept, and anything older is removed. Each file holds one day at most. The logs page still lists those days by date.

## Technical Details

* The live log is `channel.txt`. Previous days are `channel.txt.1` through `channel.txt.6`. Nothing is compressed. The logs page reads those files and labels each one with its date.
