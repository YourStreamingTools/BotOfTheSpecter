# Changelog - Version 5.7.17 (2026-08-14)

## Version Information

* Updated version from 5.7.16 to 5.7.17
* Fix: AutoMod-held spam is now denied as well as banned

## Bug Fixes

* **Spam pattern AutoMod deny never reached Twitch**
  * When a spam/bot message was held by AutoMod, the bot banned the account but left the hold in the AutoMod queue.
  * **Fix:** AutoMod-held spam is now denied as well as banned. Deny uses the same bot moderator credentials as bans, with the moderator id Twitch requires. Wired on `automod.message.hold` and `channel.chat.user_message_hold` after a spam-pattern match.

## Technical Details

* Helix: `POST https://api.twitch.tv/helix/moderation/automod/message` — scope `moderator:manage:automod`, success `204`.
