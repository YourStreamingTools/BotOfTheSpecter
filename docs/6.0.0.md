# Changelog - Version 6.0.0 (UPCOMING UPDATE)

## Version Information

* Updated version from 5.9 to 6.0.0
* Version 6.0.0 is a ground-up rewrite of the Twitch bot (`bot/beta-v6.py`), moving it to TwitchIO 3. The 5.9 stable and beta bots only receive bug fixes from here on.

## TwitchIO 3 Migration

* **New bot base**
  * The bot is now a TwitchIO 3 `commands.AutoBot`, created with `client_id`, `client_secret`, `bot_id`, `owner_id`, a list of EventSub `subscriptions` and `force_subscribe`, instead of the old IRC style bot that joined `initial_channels` with a token.
  * The bot starts inside an async context (`main()` run with `asyncio.run`), adds its own token with `add_token`, and starts without the TwitchIO token store or web adapter.
  * New `event_token_refreshed` handler keeps the channel token in step when TwitchIO refreshes it.
  * The old `event_channel_joined` handler is gone, as there is no IRC channel join in TwitchIO 3.
* **Commands**
  * Commands use the `commands.Context` style. A `setup_hook` finds every `@commands.command` on the bot class, injects the bot and registers it, and logs how many were registered.
  * The bot provides the component hooks TwitchIO 3 expects (`component_before_invoke`, `component_after_invoke`, `component_command_error`), so commands work without a separate commands component.
* **Chat over EventSub**
  * Chat now arrives through a `ChatMessageSubscription` for the channel instead of IRC.
  * Message and user fields follow TwitchIO 3: `.text` and `.chatter` replace `.content` and `.author`, and the `moderator`, `vip` and `subscriber` flags replace `is_mod`, `is_vip` and `is_subscriber`.
  * The bot ignores its own messages by checking the chatter ID against the bot ID.
  * Routines use `delta=timedelta(...)` instead of `seconds=`.
* **EventSub conduit**
  * On startup the bot looks for an existing EventSub conduit and creates one (one shard) if none exists.
* **EventSub keepalive**
  * The EventSub websocket keepalive is now 30 seconds instead of 600, so a dropped connection is noticed and reconnected much sooner.

## Lotto

* **New V6 lotto odds**
  * Each ticket now picks its result first, then builds numbers that the existing draw scores as exactly that result:
    * Division 1 (Jackpot): 1%
    * No win: 1%
    * Divisions 2 to 6: 19.6% each
  * Main and supplementary numbers never overlap, and the draw scoring itself is unchanged.
