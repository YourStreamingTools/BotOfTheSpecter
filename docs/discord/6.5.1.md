# BotOfTheSpecter Discord Bot - Version 6.5.1 (2026-10-22)

## Version Information

* Updated version from 6.5 to 6.5.1
* Fixes for webhook notices, the member join notice, log files, and live notification embeds

## Improvements

* **OpenAI webhook notices**
  * OpenAI webhooks sent to the webhook logs channel now post as their own embed with a plain-English title and description, coloured by result (for example green for completed, red for failed, grey for cancelled).
  * Covers background responses, batches, fine-tuning jobs, eval runs, incoming Realtime and Live calls, safety notices, and test notices sent from the admin Webhooks page. Unknown event types still post with their event name.
  * The embed shows the event type, the resource ID, when it happened, and the webhook ID in the footer.

## Bug Fixes

* **API key kept out of web addresses**
  * The member join notice sent to the websocket server now passes the channel's API key in the `X-API-KEY` header instead of the `/notify` web address, so it stays out of access logs.
* **Daily log files, last seven days kept**
  * At midnight each Discord log file is moved aside and a new one is started. Today's file plus the six days before it are kept as numbered files, and older ones are deleted. Nothing is compressed.
* **Quieter logs**
  * Websocket events are logged by name only. Their payloads, which carry the channel API key, are no longer written to the log.
  * Live caption events are ignored, the same as OBS events.
  * A tracked streamer who is still live is only logged once, instead of on every check.
* **Live notification embeds no longer start with a gap**
  * The tracked streamer live notification was sent with leading spaces before the stream title, which Discord mobile showed as a large gap. The title is now trimmed and the embed has no extra spacing.

## Technical Details

* Changes are in `./bot/specterdiscord.py`.
