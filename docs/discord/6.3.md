# BotOfTheSpecter Discord Bot - Version 6.3 (2026-08-04)

## Version Information

* Updated version from 6.2 to 6.3
* Fix: the Discord bot reconnects to the Specter internal WebSocket after a websocket server restart so live events keep arriving

## Bug Fixes

* **Specter WebSocket reconnect for the global listener**
  * The Discord bot registers as a global Specter WebSocket client for stream online/offline, Twitch events, schedule posts, FreeStuff, and related fan-out. After a websocket server restart, registration could fail or not re-arm cleanly, so Discord stopped receiving live events until the process was restarted.
  * **Fix:** a single manual reconnect loop owns the session (Socket.IO auto-reconnect off), with progressive backoff and connect/register timeouts. The bot sends **REGISTER** on connect and on **WELCOME**, treats the session as ready only after **SUCCESS**, and ignores stale disconnect races from a previous SID.

## Technical Details

* Changes are in `./bot/specterdiscord.py`.
