# BotOfTheSpecter Discord Bot - Version 6.3 (2026-08-04)

## Version Information

* Updated version from 6.2 to 6.3
* Critical fix: Specter internal WebSocket reconnect for the global Discord listener after websocket server restarts

## Bug Fixes

* **Specter WebSocket reconnect for the global listener**
  * The Discord bot listens as a global Specter WS client for stream online/offline, Twitch events, schedule posts, FreeStuff, and more. After a websocket server restart, registration could fail or not re-arm cleanly, so Discord stopped receiving live events until the process was restarted.
  * **Fix:** manual reconnect loop with Socket.IO `reconnection=False` (single authority), progressive backoff, 30s connect/register timeouts, **REGISTER** on `connect` and **WELCOME**, ready only after **SUCCESS**, and disconnect-race guards so a stale SID disconnect cannot wipe a fresh registration.

## Technical Details

* Changes are in `./bot/specterdiscord.py` only (in-file; no shared helper).
* Aligns with the same reconnect model used on the Twitch stable/beta bots and Kick bot in this release train.
