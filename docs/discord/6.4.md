# BotOfTheSpecter Discord Bot - Version 6.4 (2026-08-04)

## Version Information

* Updated version from 6.3 to 6.4
* Fix: stop Specter WebSocket reconnect loops that stuck on `Already connected` after a drop or hub restart

## Bug Fixes

* **Specter WebSocket sticky reconnect for the global listener**
  * Same class of failure as Twitch stable 5.7.16: a half-cleared Socket.IO client could raise `Already connected` on every reconnect attempt and never re-register, so Discord stopped receiving live fan-out.
  * **Fix:** hard client reset before connect and on errors, single **REGISTER** per transport (WELCOME no longer double-fires), and always clear ready on real disconnect.

## Technical Details

* Changes are in `./bot/specterdiscord.py`.
* See also Twitch stable [5.7.16](../5.7.16.md).
