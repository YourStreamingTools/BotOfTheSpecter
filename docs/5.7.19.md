# Changelog - Version 5.7.19 (2026-08-21)

## Version Information

* Updated version from 5.7.18 to 5.7.19
* Fix: Helix chat send re-reads the Specter app token after a 401/403

## Bug Fixes

* **Chat went silent after Helix `401 Invalid OAuth token` even when the stored Chat Token was valid**
  * Send Chat Message uses the shared Specter app token from `bot_chat_token`. The admin page and `oauth2/validate` can show that token as valid while a running bot is still presenting an older in-memory copy.
  * Custom bots already force-refreshed from the website DB and retried once. Regular Specter bots logged the 401 and stayed silent until the 60-second cache expired (or someone reminted the row).
  * **Fix:** on `401`/`403`, Specter and custom bots re-read `bot_chat_token` and retry the send once. Self-mode is unchanged — it posts with the streamer's user token, which the bot already refreshes on its own.

## Technical Details

* `send_chat_message`: `401`/`403` retry now runs when `not SELF_MODE` (covers default Specter and custom). Self-mode still uses `CHANNEL_AUTH`.
* Same retry is in beta and v6. Does not mint a new app token; it re-reads the current DB row.
