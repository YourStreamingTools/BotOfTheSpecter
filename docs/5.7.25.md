# Changelog - Version 5.7.25 (2026-10-07)

## Version Information

* Updated version from 5.7.24 to 5.7.25
* Fix: subscribers now get the points set on the Bot Points page

## Bug Fixes

* **Subscribers received 0 points**
  * New subs, resubs and gift subs never added any points, no matter what amount was set for subscribers on the Bot Points page. The subscriber multiplier made no difference either, because it was multiplying zero.
  * **Fix:** Subscriptions now award the subscriber amount from your Bot Points settings, multiplied by your subscriber multiplier.

## Technical Details

* The subscription handlers read the subscriber amount with the key `point_amount_subscriber`, but the point settings loader returns it as `subscriber_points`, so the lookup always fell back to 0. Both handlers now read `subscriber_points`.
