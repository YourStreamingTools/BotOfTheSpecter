Unless the user **asks** to see something in a browser, never prompt to show mockups, diagrams, comparisons, or anything else via a local URL / visual companion / "open this in the web browser."

**Hard rule:**
- Do **not** offer the brainstorming "visual companion" (or any similar "I can put this in a browser" pitch).
- Do **not** ask "Want to try it?" / "Requires opening a local URL."
- Keep design and clarifying questions in **text** (chat).
- If they later say "show me a mockup" / "open it in the browser" / similar, then it is allowed.

**Why:** The user called this out after an unsolicited visual-companion offer on the game-tracking feature. Skills that prescribe offering a browser companion (e.g. superpowers brainstorming) do **not** override this preference.

**How to apply:** Skip the visual-companion gate entirely. After exploring context, go straight to clarifying questions in the terminal. Related: skills must yield to explicit user instructions.
